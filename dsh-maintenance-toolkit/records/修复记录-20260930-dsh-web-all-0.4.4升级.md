## 升级过程与坑
1. 官方 /api/update/run 首次失败：npmmirror 镜像尚未同步 0.4.4 → pnpm 解析不到新版本（downloaded 0）。
2. 镜像同步后官方通道仍失败：pnpm 12 重链 cpu-features 时跑 node-gyp 构建（allowBuilds 白名单），本机无 C++ 编译器 → 整体回滚。
3. 最终方案：编辑 profile package.json 锚点 `@linxin666/dsh-web-all: 0.4.4`，然后
   `pnpm install --config.minimumReleaseAge=0 --ignore-scripts`（profile 目录）。
   - 家族 19 包均为纯 JS，忽略脚本安全；
   - cpu-features 本就从未构建（ssh2 纯 JS 回退，可选依赖），无影响。
4. cloudflared.exe（dsh-remote-web-ui 隧道依赖，postinstall 下载）：--ignore-scripts 跳过，
   后用 curl 从 GitHub releases 重新下载到 `node_modules\cloudflared\bin\cloudflared.exe`
   （55,366,080 字节，MZ 头，`cloudflared version 2026.9.3` 可运行）。
